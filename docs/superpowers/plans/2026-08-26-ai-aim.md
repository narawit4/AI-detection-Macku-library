# AI Aim Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an exclusive, generation-safe AI Aim mode that detects approved targets in a centered 320-by-320 capture and sends smooth relative Makcu movement only through the existing Trigger and Modifier gate.

**Architecture:** `AiService` owns DXCam and ONNX Runtime DirectML on a daemon worker and publishes only the latest immutable `TargetSnapshot`. Pure targeting code selects and stabilizes targets, while `MakcuService` remains the sole owner of the hardware and converts fresh snapshots into clamped relative reports through `AimMovementEngine`. Tkinter selects the exclusive mode, owns user-facing state, and marshals all service events through its existing queue.

**Tech Stack:** Python 3.11+, Tkinter/ttk, NumPy 2.5.2, DXCam 0.3.0 with its NumPy processor, ONNX Runtime DirectML 1.24.4, `makcu` 2.3.1, `unittest`, Nuitka only on explicit request.

**Spec:** `docs/superpowers/specs/2026-08-26-ai-aim-design.md`

## Global Constraints

- Windows-only; do not add cross-platform capture or input abstractions.
- Use only `models/all_games_320.onnx`; input is `float32[1,3,320,320]`, output is `[1,300,6]`, player id is `0`, and head id is `7`.
- Prefer DirectML and fall back explicitly to CPU; do not add Torch, Ultralytics, OpenCV, MSS, CustomTkinter, NDI, or Eventuri source.
- Keep Tk widget and Tk-variable access on the main thread.
- `MakcuService` remains the only code allowed to call `controller.move`.
- Jitter and AI movement are mutually exclusive.
- STOP, disable, disconnect, hotkey disable, mode change, and shutdown signal cancellation immediately and invalidate stale generations.
- Consume each target sequence at most once; discard excess and stale movement instead of queuing it.
- Preserve the user's existing uncommitted changes. Stage and commit only paths named by the active task.

@dataclass(frozen=True)
class AimSettings:
    confidence: float = 0.35
    aim_strength: float = 0.35
    smoothing: float = 0.65
    max_step: int = 20

def _aim_point(detection: Detection) -> tuple[str, float, float] | None:
    if detection.class_id == 7:
        return "head", (detection.x1 + detection.x2) / 2.0, (
            detection.y1 + detection.y2
        ) / 2.0
    if detection.class_id == 0:
        return "player", (detection.x1 + detection.x2) / 2.0, (
            detection.y1 + (detection.y2 - detection.y1) * 0.20
        )
    return None

def select_target(detections, settings, *, sequence, captured_at, previous=None):
    candidates = [
        point for detection in detections
        if detection.confidence >= settings.confidence
        if (point := _aim_point(detection)) is not None
    ]
    heads = [candidate for candidate in candidates if candidate[0] == "head"]
    candidates = heads or [c for c in candidates if c[0] == "player"]
    if not candidates:
        return None
    if previous is not None and previous.target_class == candidates[0][0]:
        associated = [
            candidate for candidate in candidates
            if math.hypot(candidate[1] - previous.aim_x,
                          candidate[2] - previous.aim_y) <= 48.0
        ]
        if associated:
            candidates = associated
            origin = (previous.aim_x, previous.aim_y)
        else:
            origin = (160.0, 160.0)
    else:
        origin = (160.0, 160.0)
    selected = min(candidates, key=lambda c: math.hypot(
        c[1] - origin[0], c[2] - origin[1]
    ))
    return TargetSnapshot(sequence, captured_at, *selected)
```

class AimMovementEngine:
    CENTER = 160.0
    DEAD_ZONE = 1.5
    MAX_AGE_S = 0.150
    MAX_ACCELERATION = 6.0

    def reset(self) -> None:
        self._last_sequence = None
        self._previous_x = self._previous_y = 0.0
        self._fraction_x = self._fraction_y = 0.0

    def step(self, snapshot, settings, now):
        if snapshot is None:
            self.reset()
            return 0, 0
        if snapshot.sequence == self._last_sequence:
            return 0, 0
        self._last_sequence = snapshot.sequence
        if now - snapshot.captured_at > self.MAX_AGE_S:
            self.reset()
            return 0, 0
        error_x = snapshot.aim_x - self.CENTER
        error_y = snapshot.aim_y - self.CENTER
        if math.hypot(error_x, error_y) <= self.DEAD_ZONE:
            self._previous_x = self._previous_y = 0.0
            self._fraction_x = self._fraction_y = 0.0
            return 0, 0
        # Apply strength, exact smoothing formula, acceleration delta,
        # max-step clamp, then only sub-integer fractional accumulation.
```

def preprocess_frame(frame):
    if not isinstance(frame, np.ndarray) or frame.shape != (320, 320, 3):
        raise ValueError("AI frame must be RGB 320x320x3")
    if frame.dtype != np.uint8:
        raise ValueError("AI frame must use uint8 pixels")
    return np.ascontiguousarray(
        frame.transpose(2, 0, 1)[None].astype(np.float32) / 255.0
    )

def model_resource_path():
    return Path(__file__).resolve().parent / "models" / "all_games_320.onnx"

class OnnxDetector:

                str(model_path), sess_options=options,
                providers=["DmlExecutionProvider", "CPUExecutionProvider"],

            self._session = factory(
                str(model_path), sess_options=options,
                providers=["CPUExecutionProvider"],

```python
def centered_region(width, height, size=320):
    if width < size or height < size:
        raise ValueError("Primary output is smaller than the AI capture region")
    left = (int(width) - size) // 2
    top = (int(height) - size) // 2
    return left, top, left + size, top + size

class DxcamCapture:
    def start(self):
        self._camera = self._camera_factory(
            output_idx=0, output_color="RGB",
            processor_backend="numpy", max_buffer_len=2,
        )
        self._camera.start(
            region=centered_region(self._camera.width, self._camera.height),
            target_fps=self._target_fps,
        )

    def read(self):
        frame = self._camera.get_latest_frame(copy=True)
        if frame is None or frame.shape != (320, 320, 3):
            return None
        return np.array(frame, dtype=np.uint8, copy=True)
```

`close` calls `stop` only when capturing and always calls `release`; both calls
are exception-isolated and the method is safe to call more than once.

```python
@dataclass(frozen=True)
class AiEvent:
    kind: str
    payload: Any = None

class AiService:
    def start(self, settings_provider):
        with self._lock:
            if self._closed:
                return None
            if self._running:
                return self._generation
            self._generation += 1
            generation = self._generation
            stop_event = threading.Event()
            self._stop_event = stop_event
            self._running = True
            self._latest = None
        self._emit(AiEvent("loading"))
        threading.Thread(
            target=self._worker,
            args=(generation, stop_event, settings_provider),
            name=f"AiInference-{generation}", daemon=True,
        ).start()
        return generation
```

The worker constructs detector then capture on its own thread, emits `ready`,
reads frames, calls `detector.detect`, passes the previous selected snapshot to
`select_target`, increments sequence for every completed inference, replaces
`_latest` under a short lock, and emits `fps` at most once per second. Every
publish and event checks generation, stop event, and closed state. `finally`
closes capture and clears running only for the current generation.

`stop` performs a lock-free event set first, then under lock increments the
generation, clears latest target, and records stopped state. It never joins on
the Tk thread. Exceptions emit `error` with a concise payload such as
`"ModelContractError: ..."`; full traceback uses `logging.exception`.
